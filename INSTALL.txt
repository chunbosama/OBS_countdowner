obs-countdown — OBS Studio 倒计时插件
======================================

【安装】
1. 右键 install.bat，选择「以管理员身份运行」。
   脚本会自动查找 OBS 安装目录；如果没找到，用命令行指定：
       powershell -ExecutionPolicy Bypass -File .\install.ps1 -ObsDir "D:\OBS Studio"
2. 完全退出并重新打开 OBS Studio。
3. 在「来源」面板点 + ，选择「倒计时」。

【手动安装】
把本目录下的 obs-plugins 和 data 两个文件夹整个复制到 OBS 安装目录
（默认 C:\Program Files\obs-studio），合并覆盖即可。

【卸载】
右键 install.bat → 以管理员身份运行，或在命令行加 -Uninstall：
    powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall

【使用】
- 属性面板里可以设定实例标签、时长（时/分/秒）、字体、文字颜色、结束颜色、
  描边、对齐，面板上方还有 开始 / 暂停·继续 / 停止 / 重置 四个按钮，方便先试跑。
- 一个场景里可以放多个倒计时，各走各的。每个实例在属性面板里单独设时长和标签。
- 绑快捷键：设置 → 热键 → 列表按【源名】分组，每个倒计时各有一组，绑定四条：
      开始倒计时 / 暂停 继续 / 停止（保留剩余） / 重置为设定时长
  给不同的倒计时绑不同的键，它们就互不影响了。
- 快速控制条：插件加载后主窗口右侧会出现「倒计时控制」面板，一行一个倒计时，
  点按钮就能开始/暂停/停止/重置，不用翻属性面板。
      想换位置就拖标题栏（位置会记住）
      拖丢了或关掉了：工具 → 倒计时控制
- 动作含义：
      开始  = 从当前剩余时间开始倒数（已结束时先回满值）
      暂停  = 冻结当前剩余时间，再按一次继续
      停止  = 停住并保留剩余时间，下次开始接着走
      重置  = 回到设定时长
- 计时只在源显示时推进：隐藏源、切到别的场景时自动冻结，回到画面后继续。

【要求】
- OBS Studio 31.x（Windows 10/11 64 位）
- 不需要额外安装 Qt 或 VC 运行库：Qt6 与 VC 运行库都是 OBS 自带/本身就需要的
